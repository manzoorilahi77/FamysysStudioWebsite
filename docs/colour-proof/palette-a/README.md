# Palette A — Voltage

Aubergine and electric magenta. All at 1440, against the static export in `out/`.

| Role              | Hex       |                                             |
| ----------------- | --------- | ------------------------------------------- |
| `pageBackground`  | `#FCF2EA` | warm blush-bone                             |
| `darkBackground`  | `#1E0B2C` | deep aubergine, near-black with a plum cast |
| `cardBackground`  | `#FFFBF7` | warm near-white                             |
| `textOnLight`     | `#210C2C` | the plum taken almost to black              |
| `textOnDark`      | `#FCEFE6` | warm bone                                   |
| `textMuted`       | `#3A1E42` | plum charcoal                               |
| `accentPrimary`   | `#B80865` | electric magenta                            |
| `accentOnDark`    | `#FF86C6` | hot pink                                    |
| `accentWarm`      | `#FF7038` | hot orange                                  |
| `accentHighlight` | `#D2FA3C` | acid lime                                   |
| `sectionAlt`      | `#3A1750` | lifted aubergine                            |
| `sectionWarm`     | `#EFDACB` | deeper sand                                 |

- [home-hero.png](home-hero.png) — the hero: aubergine ground, hot pink primary button,
  magenta serif accent, near-black header bar over it.
- [differentiator-cards.png](differentiator-cards.png) — the four panels: magenta, bone,
  hot orange, bone, on the lifted aubergine.
- [tier-cards.png](tier-cards.png) — three cards in a row, the middle one on the raised

- [closing-cta-hovered.png](closing-cta-hovered.png) — the page's one use of the acid
  lime.
- [header-over-alt-ground.png](header-over-alt-ground.png) — the header's own near-black
  ground against a section, and the light ground below it.

`node vr-serve.mjs 3100`.
