Famysys Studio · exploration 05 · set A

Six heroes. One variable: what the logo does.

Everything else is held constant — the same headline, subhead, calls to action, supporting line, navigation, right-hand accordion and bar-meter background appear in all six. The only thing that changes from one to the next is the logo's behaviour, so the comparison is between behaviours rather than between hero designs.

Every variant is scroll-driven: the logo's position and scale are read from the scroll offset each frame, so scrolling back up reverses the motion exactly. The logo lives in the masthead's brand slot and is displaced into the hero by a transform, which means the docked state is the identity transform — it cannot arrive short, arrive late, or double up.

  1. 01DrawThe mark builds itself from its own outline, and unbuilds on the way up.
  2. 02DisassembleFour parts with different weights separate, travel, and re-lock.
  3. 03MaskThe lockup is a window onto the work, and the work keeps moving.
  4. 04TrailThe logo sheds echoes; scroll speed sets how long the trail reads.
  5. 05Type collapseTracking, weight and fold resolve into the compact lockup.
  6. 06MagneticSpring-loaded lean toward the cursor, before and after docking.

Notes

Each hero has roughly a viewport and a quarter of scroll room beneath it, so the docked lockup can be looked at without the next hero arriving. One shared animation frame loop drives the whole page and only the hero currently on screen computes anything.

Fonts are Jost and Instrument Serif Italic. Imagery is the site's existing public/media/ set, referenced in place — nothing new was added.
